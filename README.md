# Система управления рецептами

## Описание

Проект для управления рецептами: создание блюд, добавление ингредиентов, масштабирование порций, формирование списка покупок и работа с диетическими рецептами.

## Использование

### Запуск тестов

1. Установите зависимости:
в терминале напишите:
pip install -r requirements.txt

2. Запустите тесты:
в терминале напишите:
python -m pytest test_recipes.py -v

## Установка
в терминале напишите:
git clone https://github.com/olgasuchinskaya/dz2_olya_tp.git
cd dz2_olya_tp
